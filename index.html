Projects

  • Home server

    RHEL 10, since September 2023

    A RHEL 10 server running about a dozen containers, each on its own LAN address through a macvlan network. Pi-hole answers DNS for local .lan names, and Caddy serves every service over HTTPS with certificates from a private CA. I moved it from Ubuntu to RHEL so I use RHCSA skills every day.

    Built with RHEL 10, Docker Compose, Caddy, Pi-hole, macvlan, NetworkManager, firewalld, SELinux, KVM, Cockpit, Tailscale

  • Camera NVR

    Frigate at two sites

    Cameras with object detection that runs locally. A Raspberry Pi 5 with a Hailo-8L handles the outdoor cameras at about 10 ms per inference. A second instance on the home server runs a YOLOv9 model on the Intel iGPU through OpenVINO. Alerts fire only for people inside chosen zones, and my own face is filtered out before anything reaches my phone.

    Built with Frigate, Hailo-8L, OpenVINO, YOLOv9, go2rtc, frigate-notify, ntfy, Caddy, Tailscale

  • Plant monitor

    ESP8266

    An ESP8266 reads a soil moisture sensor, serves the reading on a small web page behind Caddy, and pushes a moisture check to my phone three times a day.

    Built with ESP8266, Arduino, NTP, ntfy, Pi-hole, Caddy
