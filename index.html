Projects

  • Home server

    RHEL 10, since September 2023

    A RHEL 10 server running about a dozen containers, each on its own LAN address through a macvlan network. Pi-hole answers DNS for local .lan names, and Caddy serves every service over HTTPS with certificates from a private CA. I moved it from Ubuntu to RHEL so I use RHCSA skills every day.

    Built with RHEL 10, Docker Compose, Caddy, Pi-hole, macvlan, NetworkManager, firewalld, SELinux, KVM, Cockpit, Tailscale

  • Camera NVR

    Frigate, at home and for a friend

    Cameras with object detection that runs locally. For a friend, I built a Raspberry Pi 5 NVR with a Hailo-8L that handles their outdoor cameras at about 10 ms per inference, and I maintain it remotely. At home, a second instance runs a YOLOv9 model on the Intel iGPU through OpenVINO. Alerts fire only for people inside chosen zones, and my own face is filtered out before anything reaches my phone.

    Built with Frigate, Hailo-8L, OpenVINO, YOLOv9, go2rtc, frigate-notify, ntfy, Caddy, Tailscale

  • IronCard

    Self-hosted app

    A workout tracker built with Claude, which I deploy and run as a container on the home server. Its port is bound to localhost only, so the only way in is through Caddy, which adds HTTPS and a login. I reach it from my phone over Tailscale.

    Built with Docker Compose, Caddy, basic auth, private CA, Tailscale

  • Plant monitor

    ESP32-C3, version 2

    Started as an ESP8266 reading one soil sensor and pushing a moisture check to my phone. Version 2 runs on an ESP32-C3 with four soil sensors, a temperature and humidity sensor, and a relay-driven pump that waters the plants automatically.

    Built with ESP32-C3, ESP8266, DHT22, relay and 12 V pump, Arduino, ntfy, Caddy

  • This site

    GitHub Pages

    Plain HTML and CSS published from a GitHub repository to a subdomain of my own domain, with DNS in AWS Route 53. Built while learning git, and kept free of internal details.

    Built with HTML, CSS, git, GitHub Pages, AWS Route 53
