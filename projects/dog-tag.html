QR dog tag

A contact page for my dog Teddy's tag. Whoever finds him scans the QR code and can call or text me with one tap. https://teddy.techwizardsaz.com

Stack
One HTML file with inline CSS, no framework or build step
Hosting
GitHub Pages, from its own repository
Domain
Its own subdomain of techwizardsaz.com, DNS in AWS Route 53
QR code
Generated with Python's qrcode library at the highest error correction level

How it's built

  • Phone first. Big Call and Text buttons use tel: and sms: links, and the text opens with a message already started, so a stranger needs no instructions.
  • A URL I control. The QR code points at my own subdomain, not a QR service that can expire or start charging. I can change the page, or move its hosting, without reprinting the tag.
  • Built to survive a collar. The highest error correction level lets the code still scan when part of it is scratched.
  • Same workflow as this site. A CNAME record in Route 53 points the subdomain at GitHub Pages. Updates are a commit and a push.
  • DNS troubleshooting. The new subdomain loaded on my phone over cellular but not on home Wi-Fi. That pointed to a cached "doesn't exist" answer on my own network rather than a problem in Route 53, and flushing the cache fixed it.

Keeping it public-safe

  • The page shows only what a finder needs to reach me.
  • A noindex tag keeps it out of search engines. It's meant to be reached by scanning the tag.
